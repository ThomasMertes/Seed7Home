pixel

const type: pixel

Describes the color of a pixel. A pixel value uses the same color encoding as the graphics library of the operating system. The function rgbPixel(red, green, blue) creates a pixel from red, green and blue values in the range 0 to 65535. A pixel can be converted back to red, green and blue values with the function pixelToRgb(pix).

colorLookupTable

const type: colorLookupTable

Type describing a color lookup table, which maps integers to pixels. Several image formats use color lookup tables.

rgbPixel

const func pixel: rgbPixel (in integer: red, in integer: green, in integer: blue)

Creates a pixel from the red, green and blue colors of light. The range for the red, green and blue values is from 0 to 65535.
