15. NETWORK LIBRARIES

The functions getHttp, getHttps, and getFtp get data from the internet. They are defined in "gethttp.s7i", "gethttps.s7i", repectively "ftp.s7i" and return the data obtained as string. For example: 

$ include "seed7_05.s7i";
  include "gethttp.s7i";
  include "gethttps.s7i";
  include "ftp.s7i";

const proc: main is func
  local
    var string: randomData is "";
    var string: imageData is "";
    var string: readme is "";
  begin
    randomData := getHttp("testserver.host/bytes/1024");
    imageData := getHttps("seed7.net/images/mandelbr1.png");
    readme := getFtp("ftp.gnu.org/pub/README");
    ...
  end func;

Note that the locations "testserver.host/bytes/1024", etc. are not prefixed with "http://", "https://", or "ftp://" like in a URL, since the protocol used is specified by the function name.
